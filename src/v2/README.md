# FlameForge 2.0 - Cinematic Evolution

This branch tracks the development of the "Cinematic Experience" version of FlameForge.

## Architectural Goal
The core rendering engine remains stable in `src/`, while `src/v2` provides a redesigned, immersive UI/UX that leverages the existing core APIs.

## Directory Structure
- `src/v2/app/`: New entry point for the 2.0 experience.
- `src/v2/components/`: Reimagined components using cinematic UI principles (glassmorphism, fluid motion).
- `src/v2/lib/`: New utilities and hooks tailored for the 2.0 UI.
